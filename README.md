# Customer Shopping Data Analysis

## Project Overview

This project analyzes customer shopping data from shopping malls in Istanbul for the period 2021–2023.

The analysis focuses on customer gender, age groups, product categories, payment methods, products sold and revenue.

## Project Objectives

- Analyze shopping distribution by gender
- Compare products sold by gender
- Compare revenue generated by gender
- Analyze product categories
- Analyze shopping distribution by age groups
- Compare products sold by age groups
- Compare revenue generated by age groups
- Analyze payment methods
- Create an interactive Power BI dashboard
- Derive business insights from the analysis

## Tools Used

- Python
- Pandas
- Jupyter Notebook
- MySQL
- Power BI
- DAX
- GitHub

## Project Workflow

Python → Data Cleaning & Basic Analysis

MySQL → SQL Data Analysis

Power BI → Visualization & Dashboard

## Dashboard

The Power BI dashboard provides visual analysis of:

- Gender Distribution
- Gender Revenue
- Age Group Analysis
- Category Revenue
- Payment Method Distribution
- Payment Method and Gender Revenue

## Key Insights

The analysis identifies differences in shopping behavior based on gender, age group, product category and payment method.

## Conclusion

The project provides a simple business-oriented analysis of customer shopping behavior using Python, SQL and Power BI.
